# Заголовщик

Навык для [Claude Code](https://claude.com/claude-code): пишет заголовки статей для ленты Дзена, vc.ru и других площадок.

На вход даёте факты статьи. На выходе 3 варианта, у каждого указано основание: герой, беда из фактов и форма заголовка. Каждое число и событие берётся только из ваших фактов.

Внутри каталог форм взлетевших заголовков и таблица забракованных вариантов с причинами.

## Установка

Вариант 1, через git:

```bash
git clone https://github.com/aleks13620-cpu/zagolovki ~/.claude/skills/zagolovki
```

Вариант 2, вручную:

1. Скачайте архив и распакуйте его.
2. Положите папку `zagolovki` в `~/.claude/skills/`. На Windows это `C:\Users\<имя>\.claude\skills\`. Папки `skills` нет - создайте.
3. Перезапустите Claude Code.

В итоге файл должен лежать так: `~/.claude/skills/zagolovki/SKILL.md`.

## Как пользоваться

Напишите `/zagolovki` или просто «напиши заголовки к статье» и приложите текст или факты.

```text
Напиши заголовки. Факты: подрядчик выиграл контракт на 3 млн, через неделю налоговая
начислила долг 400 тысяч, заказчик может расторгнуть контракт.
```

Ответ придёт строками такого вида:

```text
Контракт выигран. Могут ли его аннулировать из-за долга по налогам? | подрядчик | может потерять контракт на 3 млн | событие, потом вопрос-угроза
```

## Под себя

- Читатель по умолчанию - собственник бизнеса. Другая аудитория меняется в начале `SKILL.md`.
- Каталог форм стоит пополнять взлётами своей ниши.
- Таблицу браков стоит дополнять своими правками: навык опирается на эти причины отказа.

## Что навык не делает

Он не проверяет факты и не обещает рост просмотров. Форму заголовка проверяйте на своей аудитории.
